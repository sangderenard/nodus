# Intention Agent Log

Timestamp: 2026-01-07 16:41:45

Purpose
- Capture the torch-dependence audit and the plan to move TensorAllocator and TensorTool onto an abstract tensor handle.

Audit Summary
- TensorAllocator currently uses `torch::Tensor*` directly in the built-in tool path (`src/thread_manager.cpp`) and is gated by `NODUS_ENABLE_TORCH`.
- Raw stack types include `VT_TORCH_TENSOR` and helpers that push/pop torch pointers.
- No abstract tensor handle exists at the tool boundary yet.

Action Plan
1) Define an abstract tensor handle and a raw stack value type for it.
2) Introduce a backend interface and a torch backend implementation that wraps torch only in backend code.
3) Refactor TensorAllocator to allocate abstract handles via the runtime backend.
4) Reintroduce font rendering via abstract tensors once the parametric vector path is ready.
5) Update tool metadata/docs to refer to abstract handles instead of torch.
6) Add build guards to ensure torch headers stay inside backend source files.
