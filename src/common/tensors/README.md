# Tensor Subsystem Scaffold

This directory is reserved for the upcoming tensor subsystem, based on the
`abstraction.py` prototype from `turing/src/common/tensors`.

Structure notes (initial pass):
- `abstraction/`: core tensor abstraction layer and shared types.
- `abstraction_methods/`: higher-level helpers and ergonomic APIs.
- `accelerator_backends/`: backend integrations (CPU, Torch, GPU, etc.).
- `autoautograd/`: experimental/autogenerated autograd plumbing.
- `backend_required_methods/`: backend interface contracts and required ops.
- `models/`: reference models or algorithm prototypes.
- `pooling/`: pooling and allocator strategies.
- `riemann/`: geometry/riemannian utilities.
- `scheduling/`: execution scheduling and graph ordering.
- `tensors/`: core tensor containers and low-level ops.
- `ops/`: op implementations and operator registry.
- `autograd/`: autograd graph, tape, and backward registration.
- `diagnostics/`: debug tooling and invariant checks.
- `runtime/`: runtime glue (dispatch, registry, config).
- `tests/`: unit tests and probes.

This scaffold is intentionally light so we can adapt the layout as the port
solidifies.
